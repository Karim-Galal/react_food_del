A responsive food ordering frontend built with React and Vite. The application allows users to browse food items, search through the menu, manage a shopping cart, and explore additional pages such as Contact and Mobile App. The project was built to strengthen my React fundamentals while practicing component-based architecture, state management, routing, and improving the overall user experience.

## Features

* Browse food items by category
* Real-time search
* Shopping cart
* Cart persistence using Local Storage
* Menu page with sorting and filtering
* Contact page with client-side validation
* Mobile App page
* Responsive layout
* React Context API for state management
* React Router for client-side routing

## Installation

Clone the repository

```bash
git clone https://github.com/Karim-Galal/react_food_del.git
```

Navigate to the project

```bash
cd react_food_del/frontend
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
